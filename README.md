# Agent Control

A sala de comando do seu time de agentes de IA. **Este repositório só distribui o app**: o site e os instaladores.

**Baixar:** [releases](../../releases/latest) · [página de download](https://davi617.github.io/AgentControl/)

| Sistema | Arquivo |
|---|---|
| Windows 10/11 (64 bits) | `AgentControl-windows-x64.zip` |
| macOS Apple Silicon / Intel | `AgentControl-macos-arm64.zip` / `AgentControl-macos-x64.zip` |
| Linux x64 / ARM64 | `AgentControl-linux-x64.tar.gz` / `AgentControl-linux-arm64.tar.gz` |
| Android | `AgentControl-android.apk` |

Cada versão traz `SHA256SUMS.txt` para conferir o download.
