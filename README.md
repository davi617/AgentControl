### Conheça o Agent Control

- **Central de Missões:** acompanhe objetivos, etapas e resultados do time de agentes.
- **AgentC e HUD:** uma visão de controle e acompanhamento da atividade.
- **Vários agentes em um só lugar:** organize ferramentas como Claude Code, Codex, Hermes e outras conforme suas instalações.
- **PC + celular:** aplicativos para Windows, macOS, Linux e Android, além de acesso pelo navegador no iPhone/iPad conforme o guia.

**O site é o ponto de entrada para downloads.** Clique no botão do seu sistema e o arquivo começa a baixar diretamente, sem precisar navegar pela lista de versões do GitHub. Confira a soma SHA-256 apresentada na seção de downloads antes de instalar.

### Este repositório é público; o código-fonte atual não é

Este repositório contém **a landing page, documentação de instalação e os links para os instaladores oficiais**. O código-fonte atual do Agent Control é mantido separadamente em um repositório privado.

> A versão atual é proprietária (todos os direitos reservados). As versões publicadas até **4.3.0** sob a licença MIT continuam com os direitos concedidos pelas licenças originais.
