Conheça o AgentC

Um mascote que mostra o que está acontecendo.

Ele pisca, olha em volta e reage ao time. Lembra o que você pede ("lembra que…"), dá um resumo quando você chega e ri se você fizer cócegas.

Recursos

Feito para rodar o dia todo.

Baixar

Escolha o seu sistema.

Grátis e de código aberto. O app do PC já vem com tudo o que precisa para rodar.

# servidor + fila anti-429 (Node 24+)
$ git clone https://github.com/OWNER/AgentControl && cd AgentControl
$ npm install && npm start      # http://127.0.0.1:20150

# Linux e macOS: instala servidor, app e atalho
$ bash tools/instalar.sh --agentes --autostart

# escolher só os agentes que você usa
$ AgentControl --time claude,hermes

Monte o seu time hoje.

Pode começar só com o Claude Code e adicionar os outros quando quiser.
