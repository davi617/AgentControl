Instalação

Como instalar

Comece pelo PC, que executa a sala e os agentes. Depois, configure o acesso pelo celular.

Windows

Windows 10 e 11 de 64 bits.

macOS

Pacotes para Apple Silicon e Intel.

Linux

Pacotes x64 e ARM64 para X11 ou XWayland.

Android

App por APK ou acesso pelo Chrome.

iPhone e iPad

Acesse o Agent Control pelo Safari e adicione o atalho à Tela de Início.

Raspberry Pi e terminal

Pacote Linux ARM64 e opções para uma instalação licenciada em terminal.
