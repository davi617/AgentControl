Baixar (x64)ARM64

Jeito mais fácil: o instalador

  1. Instale o Node 24 e o .NET 8

    Pela sua distribuição (ou nvm para o Node). O instalador avisa se faltar algo.

  2. Rode o instalador

    $ git clone https://github.com/SEU-DONO/AgentControl && cd AgentControl
$ bash tools/instalar.sh --agentes --autostart

    Ele instala o servidor, o app e o atalho no menu. --sem-app instala só o servidor (máquina sem tela).

  3. Abra o Agent Control pelo menu de apps

    Escolha o time em Ajustes → Seu time e toque em Ligar tudo.

Pelo .tar.gz

$ tar xzf AgentControl-linux-x64.tar.gz
$ ./AgentControl/AgentControl
