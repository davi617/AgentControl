Raspberry Pi e terminal

Sem tela? A sala roda no terminal, por SSH ou num Raspberry Pi 4/5, com o AgentC e a caixinha de fala. Um Arduino acende um LED por agente.

Raspberry Pi

  1. Sistema 64 bits e Node 24

    Raspberry Pi OS 64 bits (Pi 4 ou 5).

  2. Instale e deixe ligado sozinho

    $ git clone https://github.com/SEU-DONO/AgentControl && cd AgentControl
$ bash tools/raspberry/instalar.sh

    Fica ligado pelo systemd, só em 127.0.0.1.

Só terminal (Linux, SSH)

$ node tools/terminal/sala.mjs

Arduino

$ node tools/arduino/ponte.mjs /dev/ttyACM0

Aceso: trabalhando. Pisca rápido: travado. Pisca devagar: pronto. O buzzer apita com fala nova.
