Instalar

macOS

Launcher, HUD, AgentC e ícone na barra de menus. Apple Silicon (M1 em diante) e Mac com Intel.

Baixar (Apple Silicon)Mac com Intel

Passo a passo

  1. Instale o Node 24

    Pelo site nodejs.org ou pelo Homebrew:

    brew install node@24

  2. Descompacte e mova para Aplicativos

    Dê dois cliques no .zip e arraste o AgentControl para a pasta Aplicativos.

  3. Abra pela primeira vez com o botão direito

    Clique com o botão direito → Abrir → Abrir. O macOS só pergunta na primeira vez (o app ainda não tem notarização da Apple). Se não deixar, vá em Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim.

  4. Escolha o seu time e ligue

    Em Ajustes → Seu time marque os agentes e toque em Ligar tudo.

Pelo terminal (instala servidor, app e atalho)

$ git clone https://github.com/SEU-DONO/AgentControl && cd AgentControl
$ bash tools/instalar.sh --agentes --autostart
