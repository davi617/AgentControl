Instalação

macOS

Pacotes para Apple Silicon e Intel.

Baixar (Apple Silicon)Mac com Intel

Passo a passo

  1. Instale o Node 24

    Pelo site nodejs.org ou pelo Homebrew:

    brew install node@24

  2. Descompacte e mova para Aplicativos

    Dê dois cliques no .zip e arraste o AgentControl para a pasta Aplicativos.

  3. Abra o Agent Control

    Use o aplicativo que você extraiu. Confira o SHA-256 da publicação se quiser verificar o ZIP.

  4. Escolha o seu time e ligue

    Em Ajustes → Seu time marque os agentes e toque em Ligar tudo.

Baixar pelo terminal

$ gh release download v5.0.0 -R davi617/AgentControl --pattern "AgentControl-macos-arm64.zip"

Para Mac Intel, escolha o pacote AgentControl-macos-x64.zip. O código-fonte da versão atual é privado.
