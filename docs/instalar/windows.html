Instalar

Windows

Launcher, HUD no topo da tela, AgentC, código ao vivo e ícone na bandeja. Windows 10 e 11, 64 bits.

Baixar para Windows

Passo a passo

  1. Instale o Node 24

    O servidor da sala roda em Node. Baixe a versão LTS em nodejs.org ou rode:

    winget install OpenJS.NodeJS.LTS

  2. Descompacte o .zip

    Clique com o botão direito em AgentControl-windows-x64.zip → Extrair tudo. Coloque numa pasta sua (ex.: Documentos\AgentControl), fora de Arquivos de Programas.

  3. Abra o AgentControl.exe

    Se o Windows mostrar "O Windows protegeu o computador", toque em Mais informações → Executar assim mesmo (o app ainda não tem certificado pago).

  4. Escolha o seu time

    Em Ajustes → Seu time marque os agentes que você usa (Claude Code, Codex, Gemini, Qwen…). Depois toque em Ligar tudo na aba Início.

  5. (Opcional) Iniciar com o Windows

    Em Ajustes, ligue Iniciar com o Windows. O HUD aparece no topo e os serviços sobem sozinhos.

Para quem prefere o terminal

$ git clone https://github.com/SEU-DONO/AgentControl
$ cd AgentControl
$ npm install
$ npm start   # sala em http://127.0.0.1:20150

Deu problema?

A sala não abre

Veja a aba Logs do Launcher. Normalmente é o Node faltando ou outra coisa usando a porta 20150.

Antivírus reclamou

Apps novos sem assinatura paga às vezes caem em alerta. Confira o hash no SHA256SUMS.txt da versão no GitHub.
